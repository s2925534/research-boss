## Status Guide

- 🟡 **Pending** - Not done yet. Applied automatically to any unchecked item that has no other status tag — don't hand-add it.
- 🟢 **Done** - Completed and already implemented, not independently re-verified. Completed items keep `Done` and add a second category flag after it.
- ✅ **Done Done** - Implemented AND independently re-verified/tested end-to-end. A stricter claim than `Done` — only upgrade an item to this once you've actually confirmed it works, not just implemented it.
- 🔵 **Deterministic** - Local, rule-based, non-AI work that can usually be implemented and tested now.
- 🟠 **AI** - Requires explicit AI design, opt-in flags, privacy warnings, and tests before implementation.
- 🟣 **API** - Requires external API, backend API, UI/API contract, or integration-boundary work.

Each item below carries a status dot (🟡 Pending · 🟢 Done · ✅ Done Done) and a category dot (🔵 Deterministic · 🟠 AI · 🟣 API), the same colors used in `TODO.html`. `scripts/colorize_todo_md.py` maintains both automatically from the `**Tag**` chain — don't hand-edit the dots themselves, just the tags.
